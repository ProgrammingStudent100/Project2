Club About

The computing club is a club at El Camino College dedicated for topics that are less explored, such as cybersecurity, web development, and data science. Meetings are held every Tuesday in MBA 320 with the focus being on workshops to improve these skills.

What We Cover

Learn various programming languages including Python, Java, and JavaScript. Build real-world applications and work on collaborative coding projects.

Explore network security, ethical hacking, and encryption techniques. Participate in Capture The Flag competitions and learn to protect digital systems.

Learn neural networks, data science, and AI algorithms. Use frameworks like TensorFlow and build applications.

Learn front-end and back-end web technologies including HTML, CSS, React, and Node.js. Make responsive websites and modern web applications.
